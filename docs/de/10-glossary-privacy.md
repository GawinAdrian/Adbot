# 10 · Glossar und Datenschutz

**Stand:** 2026-11-01

## Datenschutz in einfachen Worten

**Wo liegen deine Daten?** Berichte, Einstellungen und Ergebnisse liegen als Dateien **auf deinem Rechner** (`.adbot/` im Adbot-Ordner und `~/.config/adbot/standard`). Sie sind nicht im Repository.

**Wohin gehen Daten?**
- An **Google**: Adbot liest dein Konto über Googles Schnittstelle (nur lesend).
- An **Claude (Anthropic)**: Alles, was in einem Gespräch auftaucht (z. B. Zahlen aus einem Bericht, den du Claude zeigst), wird zur Verarbeitung dorthin gesendet. Zeige Claude nur, was du zeigen willst.
- **Nicht** an Dritte durch das Cockpit: Die Seite ist eine lokale Datei ohne Netzwerkzugriffe.

**Was nie gespeichert wird:** Passwörter, Schlüssel und Anmeldedateien stehen nie in Berichten oder im Repository. Im Profil steht höchstens die Projekt-ID.

**Konten anderer Personen:** Wenn du das Konto eines Kunden oder Familienmitglieds betreust, klärt vor der Nutzung mit einer qualifizierten Stelle, ob eine Vereinbarung zur Auftragsverarbeitung nötig ist. Das ist **keine Rechtsberatung**.

**Löschen:** Trennen (Anleitung 03) und die Ordner löschen. Das Löschen lässt sich nicht rückgängig machen.

## Glossar

| Begriff | Englisch | Erklärung |
|---|---|---|
| **Kampagne** | campaign | Oberste Ebene im Konto: legt Budget, Ziel, Region und Zeitplan fest. |
| **Anzeigengruppe** | ad group | Bündelt Anzeigen und Keywords zu einem Thema innerhalb einer Kampagne. |
| **Keyword** | keyword | Suchbegriff, bei dem die Anzeige erscheinen soll. |
| **Ausschließendes Keyword** | negative keyword | Suchbegriff, bei dem die Anzeige nicht erscheinen soll. Nur mit Suchbegriffsbericht festlegen. |
| **Keyword-Option** | match type | Steuert, wie genau eine Suche zum Keyword passen muss (genau, Wortgruppe, weitgehend). |
| **Responsive Suchanzeige** | responsive search ad | Anzeige aus mehreren Titeln und Beschreibungen; Google kombiniert sie automatisch. |
| **Anzeigentitel** | headline | Die fett dargestellte erste Zeile der Anzeige. |
| **Beschreibung** | description | Der erklärende Text der Anzeige. |
| **Impression** | impression | Eine Anzeige wurde einmal angezeigt. |
| **Klick** | click | Jemand hat auf die Anzeige geklickt. |
| **Klickrate (CTR)** | click-through rate (CTR) | Klicks geteilt durch Impressionen, in Prozent. |
| **Kosten pro Klick (CPC)** | cost per click (CPC) | Durchschnittlicher Preis für einen Klick. |
| **Conversion** | conversion | Eine gewünschte Handlung, z. B. Anruf, Formular oder Kauf. |
| **Conversion-Rate** | conversion rate | Anteil der Klicks, die zu einer Conversion führen. |
| **Kosten pro Conversion (CPA)** | cost per acquisition (CPA) | Kosten geteilt durch Conversions: was eine Anfrage oder ein Kauf kostet. |
| **Werbekostenrentabilität (ROAS)** | return on ad spend (ROAS) | Umsatz geteilt durch Werbekosten. |
| **Tagesbudget** | daily budget | Durchschnittlicher Betrag, den eine Kampagne pro Tag ausgeben darf. |
| **Gebotsstrategie** | bidding strategy | Legt fest, wie Google für dich bietet (z. B. Klicks maximieren, Ziel-CPA). |
| **Qualitätsfaktor** | quality score | Schätzwert von Google für die Qualität von Keyword, Anzeige und Zielseite. |
| **Suchbegriff** | search term | Was Nutzer tatsächlich bei Google eingegeben haben. |
| **Zielseite** | landing page | Die Seite, auf der Nutzer nach dem Klick landen. |
| **Asset** | asset | Zusatzelement zur Anzeige, z. B. Anruf, Sitelink oder Bild. |
| **Anteil an möglichen Impressionen** | impression share | Wie oft die Anzeige erschien, verglichen mit dem Möglichen. |
| **Lernphase** | learning phase | Zeit nach größeren Änderungen, in der das System noch lernt; Werte schwanken. |
| **Remarketing** | remarketing | Anzeigen für Personen, die bereits auf deiner Website waren. |
| **Standort-Targeting** | location targeting | Region oder Umkreis, in dem die Anzeige erscheint. |
| **Sprach-Targeting** | language targeting | Sprache der Nutzer, die erreicht werden sollen. |
| **Anzeigenplaner** | ad schedule | Wochentage und Uhrzeiten, zu denen Anzeigen laufen. |
| **Conversion-Tracking** | conversion tracking | Messung, welche Klicks zu einer Anfrage oder einem Kauf führen. |
| **Finale URL** | final URL | Die Adresse der Seite, auf die die Anzeige führt. |
| **Verwaltungskonto (MCC)** | manager account (MCC) | Konto, das mehrere Google-Ads-Konten verwaltet. |
